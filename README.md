# Week 4 - Predictive Modeling and Optimization in Logistics

This project uses a Jupyter Notebook to predict logistics delivery time and connect the predictions to practical optimization decisions.

## Workflow
Data loading → inspection → preprocessing → train/test split → Linear Regression → Random Forest → MAE/RMSE/R² → cross-validation → hyperparameter tuning → delay-risk prediction → optimization strategy.

## Run
```bash
pip install -r requirements.txt
jupyter notebook Week_4_Logistics_Predictive_Modeling.ipynb
```

The dataset is simulated for academic practice.
